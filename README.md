# Sandlot Home Run Derby

Family home run derby for iPhone Safari (and Add to Home Screen). Original cartoon art, personal/family use.

Open `index.html` from a local web server so audio can start and the scripts load:

```
python3 -m http.server 8080
```

Then visit the page in Safari. Derby and Pass & Play (2–4 kids, 10 swings each) are playable. Brackets and the pickle rundown are still coming.
